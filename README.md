# 🐝 Kavin R K — Portfolio

A clean, glassy portfolio site with a bumblebee yellow theme, dark/light toggle, and a hidden easter egg.

---

## 📁 Folder Structure

```
kavin-portfolio/
├── index.html      ← Main page
├── style.css       ← All styles (glass + themes)
├── script.js       ← Theme toggle, animations, easter egg
├── photo.jpg       ← YOUR PHOTO (add this!)
└── README.md
```

---

## 🚀 Quick Start in VS Code

### Step 1 — Add your photo
Copy your photo file into this folder and rename it:
```
photo.jpg
```
*(It should be your portrait image — the Copilot_20260526... file you provided)*

### Step 2 — Open in VS Code
```bash
code kavin-portfolio
```

### Step 3 — Install "Live Server" extension
- Open Extensions panel: `Ctrl+Shift+X`
- Search: **Live Server** (by Ritwick Dey)
- Click **Install**

### Step 4 — Launch
- Right-click `index.html` in the Explorer panel
- Click **"Open with Live Server"**
- Your browser opens at `http://127.0.0.1:5500`

> **No dependencies. No npm. No build step. Pure HTML/CSS/JS.**

## 🥚 Easter Egg (Hidden!)

Two ways to trigger the secret S.T.A.R.S. terminal:

| Method | How |
|--------|-----|
| **Bee clicks** | Click the 🐝 in the footer **5 times** quickly |
| **Konami Code** | Keyboard: `↑ ↑ ↓ ↓ ← → ← → B A` |

Inside the terminal, type `help` to see available commands.
